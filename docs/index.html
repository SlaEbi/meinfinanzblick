Features

Acht Bereiche für deine Finanzsicherheit

Von der Kontoverwaltung bis zur Steuerprognose — alles was du für finanzielle Klarheit brauchst.

Finanzüberblick

Konten, Depots und Sachwerte in einer Ansicht. Nettovermögen und Net-Worth-Verlauf als Chart — immer aktuell.

Darlehen & Tilgung

Tilgungspläne mit Sondertilgung, Zinsbindungs-Warnungen und Restschuld-Verlauf als Chart — kalenderjahrgenau.

Spending Plan

Monatliches Budget strukturiert planen. Einnahmen, feste und variable Ausgaben erfassen. Saldo auf einen Blick.

Sparziele

Sparziele mit Sparschwein-Fortschritt und automatischer Zielrate-Berechnung. Manuelle „Fütterungen" machen jeden Schritt sichtbar.

Steuerprognose

Einkommen- und Gewerbesteuer vorausberechnen — inkl. Kinderfreibetrag-Günstigerprüfung, Gewerbesteuer-Zerlegung nach Gemeinden und Rücklagen-Empfehlung fürs Finanzamt.

Rechner

Zinseszins-Simulator, Darlehensrechner und Kapitalentnahmerechner — Szenarien in Sekunden durchspielen, bevor du sie im echten Leben triffst.

Versicherungen & Verträge

Alle Policen, Laufzeiten und Kündigungsfristen zentral erfasst. Automatische Warnungen bei nahenden Fristen.

Notfall & Nachlass

„Wo liegt was" für deine Familie. Kontakte, Dokumente und Sofortmaßnahmen — strukturiert für den Ernstfall.

Datenschutz

Deine Daten. Nur auf deinem Mac.

Keine Cloud. Keine Abonnements. Keine Weitergabe. Alles bleibt lokal als SQLite-Datenbank auf deinem Gerät.

100 % lokal

Die App läuft ausschließlich auf deinem Mac. Kein einziges Byte verlässt dein Gerät.

Keine Passwörter gespeichert

MeinFinanzblick ist eine Landkarte, kein Tresor. Zugangsdaten bleiben in deinem Passwort-Manager.

Einfaches Backup

Eine einzige Datei sichern — auf USB-Stick oder extern. Mit einem Klick in der App.

Einrichtung

In drei Schritten startklar

Python installieren, klonen, einrichten. Danach läuft die App per Doppelklick — kein Terminal mehr nötig.

# 1. Repository laden
git clone github.com/SlaEbi/meinfinanzblick
cd meinfinanzblick

# 2. Einrichten (einmalig)
make setup

# 3. Starten
Doppelklick → MeinFinanzblick.app
